# Contributing to Roll Model

Roll Model is written and maintained by its author alone, with a lot of AI help (see the note at the top of the README). **Pull requests are not accepted** and will be closed. You are welcome to fork it under the terms of the [PolyForm Noncommercial License 1.0.0](LICENSE).

## What is welcome

Bug reports and results from real hardware, as issues. The Roland V31 note map, the hi-hat pedal handling and the controller presets were never tried on a real device. `HANDOFF.md` lists what is unverified (the tasks starting `HW-`) and `docs/hardware-test-plan.md` is a step-by-step plan with a results sheet. A report such as "on my TD-17 the open hi-hat arrives as note 46 with CC#4 at 0", with what the monitor on Settings → MIDI input showed, is worth more than a patch.

## Reporting a problem

Open an issue and fill in the form. Say which version you run (the start-up screen shows it), your operating system, the drum module or controller and how it is connected. For a score that does not load, attach the file only if you may share it, or say which program exported it.

Security problems go to [SECURITY.md](SECURITY.md), not to a public issue.

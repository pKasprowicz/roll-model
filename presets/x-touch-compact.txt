# Behringer X-Touch Compact in Mackie Control (MC) mode.
# (Written with extensive use of AI, from the Mackie Control table as remembered; not verified on the device.)
#
# NOT TESTED on a device: it follows the standard Mackie Control note and cc
# numbers. Check it with the monitor in Settings -> Controller; if a number
# differs, copy this file into the controllers folder, change the number and
# choose the copy.
#
# Eight faders: the volume of the eight instrument groups (Kick, Snare, Hi-hat, Tom 1,
# Tom 2, Tom 3/4, Crash, Ride). The ninth (main) fader: the music volume. The faders are
# not moved by the application; a fader takes over once it reaches the value shown.
# The three rows of buttons above the faders: REC plays the group, SOLO and MUTE do what they say.
# The row of eight encoders on top: tempo, first bar, last bar, click volume, count-in,
# bars per row, (unused), recent scores. The push of an encoder: encoder 1 = 100 % tempo,
# encoder 8 = open the score.
# The six buttons on the right: rewind / fast forward = range back / forward, stop, play = listen,
# record, cycle = loop.
# The SELECT row under the faders (the Compact has no other free buttons whose message is known)
# holds the rest, left to right: Shift, Click, Notes, Metronome, Tap tempo, Loop worst bar,
# Discard take, Next tab. The eight encoders on the right and the LAYER A / B buttons are not used:
# what they send in MC mode is not known (find out with the monitor).
# While the Rudiments tab's practice is in use, "first bar" = repeats, "last bar" = which hand
# leads and the recent-scores encoder = the rudiment; the tempo is in BPM.

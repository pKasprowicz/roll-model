# Korg nanoKONTROL2 in CC mode (not Mackie Control).
# (Written with extensive use of AI, from the factory CC table as remembered; NOT verified on the device.
# A web search confirmed only that the record button sends cc 64 in CC mode.)
#
# The nanoKONTROL2 starts in a Mackie-like mode. Switch it to CC mode: hold SET MARKER and CYCLE
# while plugging in the USB cable. Check every number with the monitor on Settings -> Controller; if one
# differs, copy this file into the controllers folder, change the number and choose the copy.
#
# Strips 1-8:  fader cc 0-7 (volume of the instrument groups), knob cc 16-23, S cc 32-39 (solo),
#              M cc 48-55 (mute), R cc 64-71 (play the group).
# Knobs:       tempo, first bar, last bar, count-in, bars per row, click volume, music volume, (unused).
# Transport:   play = listen, stop, rewind / fast forward = range back / forward, record, cycle = loop.
# Track < >:   tempo -5 / +5. Marker set / < / >: tap tempo, click, notes.
# Absolute knobs and faders take over once they reach the current value, so nothing jumps.

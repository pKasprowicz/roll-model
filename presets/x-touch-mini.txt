# when the two LAYER buttons are pressed.
#
# The note and cc numbers are those of the Mini's Mackie Control table as I know it;
# they have not been checked on the device. Press every control with the
# controller selected in Settings -> Controller and read the monitor there: if a
# number differs, copy this file into the controllers folder, change the number
# and choose the copy.
#
#   top row of buttons    89 90 40 41 42 43 44 45
#   bottom row of buttons 87 88 91 92 86 93 94 95
#   encoders 1-8          cc 16-23 (turn, relative), notes 32-39 (push)
#   fader                 pitch bend, channel 1
#   LAYER A / LAYER B     notes 84 / 85
#
# Layer A: the bottom row has the symbols printed on the device, and does what they say:
#          [MC] [ ] rewind fast-forward LOOP stop play record
#          = Loop worst bar · Discard take · Range back · Range forward · Loop · Stop · Listen · Record
#          (rewind and fast forward step the selected measures back and forward).
#          The top row: Shift (hold) · Tempo -5 % · Tempo +5 % · Click · Tap tempo · Notes · Metronome tab · Next tab
# Layer B: mute (top row) and solo (bottom row) of eight instrument groups, their volume on the encoders.
#
# While the Rudiments tab's practice is in use, layer A's measure controls mean something else
# (no change to this file is needed): encoder 2 = repeats, encoder 3 = which hand leads, encoder 8
# = the rudiment (turn), "range back" / "range forward" = previous / next rudiment, the tempo
# controls are in BPM, and the push of encoder 1 goes back to the rudiment's starting tempo.
